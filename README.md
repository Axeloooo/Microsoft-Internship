## Vector Addition

1. Go to the root directory of the module.

```bash
cd src/vector_add
```

2. Compile the CUDA code.

```bash
make build
```

3. Run the CUDA code.

```bash
make run
```

4. Clean up the build files.

```bash
make clean
```
