# Microsoft Internship Documentation

Welcome to the documentation for the Microsoft Internship Project. This guide covers the CUDA implementations of BLAS operations and custom collective algorithms developed during the internship.

## Contents

- **BLAS Kernels**: High-performance implementations for AXPY, Dot Product, Reduction, and GEMM.
- **Collective Kernels**: Custom AllReduce strategies including One-Shot, Two-Shot, and User-Buffers methods.

Refer to the sidebar or the [Summary](./SUMMARY.md) for detailed pages on each kernel.

Happy Coding!
